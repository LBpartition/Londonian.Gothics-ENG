TRANSLATING LONDONIAN GOTHICS TO OTHER LANGUAGES
================================================

You need: Windows, Python 3, and these Python packages:
    pip install pillow keystone-engine ndspy

All commands below are run from the .WORK folder.


1. ADD YOUR ROM
---------------
Put the untranslated Japanese ROM (game code ALGJ) here, with this exact name:
    .WORK\rom\JPN-original.nds

Then run once:
    python tools\phase1_baseline.py
This extracts the ROM into .WORK\extracted\ (needed by the build).


2. FILES TO EDIT (all in .WORK\tools-resources\)
------------------------------------------------
script_en.json      ALL text in the game. Replace the English with your language.
                    Sections: intro, dialogue (in playthrough order), locations,
                    dresses, items, menu.
                    - Text is stored as a list of the exact lines shown in-game.
                    - {H}word{/H} = word shown in red.
                    - Dialogue boxes show 3 lines; a blank line "" pads a box so
                      the next line starts in a new box.
                    - "source" only records where the English came from; you can
                      ignore it.

script_jp.json      The original Japanese, in the same order. Reference only.

SCRIPT - FULL.txt   The same text as script_en.json as a plain readable script.
                    You can edit this instead of the JSON (see step 3).

glyph_table.tsv     The font. Each character your text uses must be listed in the
                    "en" column. The game shows all text in capitals (your text
                    is converted to upper case), so only capital letters are
                    needed. Accented capitals (e.g. É, Ü) are not in the font
                    yet - add them as new CUSTOM rows at the end:
                      id      next number after the last row (0x273, 0x274, ...)
                      char/en the character
                      top     first pixel row of the glyph (3 = capital-letter top)
                      pixels  rows separated by "/", "." = empty, 1-3 = shade
                    Copy an existing CUSTOM row (e.g. letter A) as a template.

ShadowRisae-Guide.txt   The English GameFAQs guide the translation is based on.
                        Reference only.


3. SCRIPTS TO RUN
-----------------
If you edited SCRIPT - FULL.txt, copy the edits into script_en.json:
    python tools\script_import.py
(Change text only; do not add, remove or reorder entries.)

Build the patched ROM and check that all text fits:
    python tools\full_build.py out MyTranslation
  -> out\MyTranslation.nds
  -> out\fit_report.tsv   any line marked FAIL is too long for its box: shorten
                          it or change its line breaks, then build again.

Regenerate SCRIPT - FULL.txt from script_en.json (to see your exact in-game
line breaks, or after editing the JSON):
    python tools\script_dump.py


4. NOT IN script_en.json
------------------------
- Title screen credit lines: tools\title_text.py (default_lines). Pass a
  third argument to full_build.py (e.g. "python tools\full_build.py out MyTranslation 1")
  to show them.
- The intro and SAVE/LOAD prompts are drawn as images with the Windows Georgia
  font (tools\intro_patch.py, tools\save_load_patch.py); they use the text from
  script_en.json but may need a different font for non-Latin scripts.
